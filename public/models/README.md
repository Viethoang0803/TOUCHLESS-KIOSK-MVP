# MediaPipe Hand Landmarker Model

Đặt file model vào thư mục này với tên: **hand_landmarker.task**

## Cách tải

1. Truy cập: https://developers.google.com/meditapipe/solutions/vision/hand_landmarker
2. Tải model **hand_landmarker.task** (float16/lite)
3. Copy file vào `public/models/hand_landmarker.task`

Hoặc tải trực tiếp:

```bash
curl -L -o public/models/hand_landmarker.task \
  "https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task"
```

Ứng dụng sẽ load model từ đường dẫn: `/models/hand_landmarker.task`
